# RelationScope v1.0.0

RelationScope v1.0.0 is the first production release of the project.

## What ships in v1.0.0

- ModernBERT-base relation classifier with explicit HEAD/TAIL entity markers.
- Entity-aware pooling using CLS + HEAD + TAIL + |HEAD - TAIL|.
- Temperature-scaled confidence.
- Open-set relation detection with `UNKNOWN_RELATION`.
- Three frozen operating profiles:
  - High coverage: 0.924
  - Balanced: 0.967
  - High safety: 0.978
- FastAPI inference service.
- Next.js product interface.
- Public web service backed by a private Cloud Run API.
- GCS model bundle publication with SHA-256 manifest verification.
- Terraform-managed Cloud Run, IAM, Artifact Registry and GCS.
- CPU-only production serving with scale-to-zero.

## Final model

`modernbert-open-set-v1.1`

Protocol:

`fewrel_open_set_56_known_8_calibration_unknown_16_test_unknown`

### Known-relation test

- Accuracy: 89.21%
- Macro-F1: 89.16%
- Top-3 accuracy: 98.01%
- ECE: 1.95%

### Final unseen-relation test — balanced profile

- OOD AUROC: 80.33%
- OOD AUPRC: 90.50%
- Unknown-F1: 85.30%
- Known acceptance: 61.25%
- Unknown rejection: 84.45%

The balanced threshold 0.967 was frozen from validation-known + calibration-unknown data before the final unseen test.

## Production latency

Warm Google Cloud Run CPU deployment, 2 vCPU / 4 GiB:

- Application median: 87.2 ms
- Application mean: 94.2 ms
- End-to-end client median: 138.0 ms
- End-to-end client mean: 157.3 ms

GPU benchmarks remain documented separately and are not presented as Cloud Run production latency.

## Architecture

```text
Browser
   ↓
Public Next.js Cloud Run
   ↓  Google-signed identity token
Private FastAPI Cloud Run
   ↓
Versioned GCS model bundle
   ↓
ModernBERT + calibrated open-set inference
```

## Release guarantees

- final unseen relations were not used to select operating thresholds;
- production model artifacts are verified against a SHA-256 manifest;
- the API is private and invoked by the web service account;
- raw trained weights and Terraform variable files are not committed to Git;
- the production frontend and API have both been smoke-tested with live inference.

## Next

v2 development starts after this release freeze and will focus on observability, feedback/human review, asynchronous batch workflows, model lifecycle management, and retraining workflows.

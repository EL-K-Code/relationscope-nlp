# Legacy ENSAI notebook

The project originated from an ENSAI Advanced NLP lab completed by Maxime Ferret and Alex Komla Labou.

The original notebook explored LSTM classification, seq2seq attention and T5 on FewRel. It is intentionally kept separate from production code because RelationScope changes the evaluation protocol and rewrites the pipeline for reproducibility.

Do not copy notebook metrics into the project README or CV until they have been reproduced by the scripts in this repository.
